# Especificación 006: Agenten Contextual

## 1. Objetivo

Ofrecer un chat para hacer consultas financieras y documentales en lenguaje natural al agente CFO. La implementación de interfaz vive en `src/features/agent_cfo_chat/` y reutiliza el shell, el tema y las traducciones de WaveCore.

## 2. Navegación

- El item `Agenten Contextual` aparece en la sección Documentación, inmediatamente después de `Repositorio`.
- El item navega a `/agent-cfo-chat` y la ruta carga el chat dentro de `AppShell`.

## 3. Contrato de consulta

- La interfaz envía `POST /api/agent_cfo` al servidor indicado por `VITE_API_BASE_URL`.
- El cuerpo JSON tiene la forma `{ "question": "...", "conversation_id": "UUID" }`. En la primera petición de una ventana se omite `conversation_id`; se recortan espacios exteriores y se limita la consulta a 2000 caracteres.
- La respuesta incluye `answer`, `model`, `conversation_id`, `sources` y `consulted_sources`. Cada fuente contiene `id`, `type`, `reference` y `details`; los tipos admitidos son `pdf`, `products`, `table`, `sales`, `purchases` y `stock`.
- La respuesta, el UUID y las fuentes se validan antes de mostrarse. Las referencias se presentan bajo la respuesta del agente para que la procedencia sea accesible como texto, no sólo mediante color.
- El frontend conserva el `conversation_id` únicamente en el estado de la página y lo reutiliza en consultas posteriores y reintentos. Una nueva instancia de la página no reutiliza el ID anterior. Las preguntas y respuestas visibles tampoco se persisten en el cliente.

## 4. Comportamiento y errores

- El usuario puede enviar mediante el botón o Enter; Shift+Enter conserva el salto de línea.
- Mientras se consulta, se bloquea el compositor y se muestra un estado de carga.
- Ante un error se conserva la pregunta y se ofrece reintentar manualmente, sin enviar consultas automáticamente.
- Configuración ausente, fallo de red, timeout, rechazo de consulta, error de autorización, respuesta inválida y fallo de servidor se muestran como estados distintos y traducidos.
- Textos visibles y accesibles están disponibles en catalán, español e inglés.

## 5. Criterios de aceptación

1. El item de navegación aparece después de Repositorio, enlaza a `/agent-cfo-chat` y queda activo en esa ruta.
2. Una consulta válida se envía al endpoint CFO con el campo `question` y se muestra el `answer` recibido.
3. Las fuentes recibidas se muestran junto a la respuesta con tipo y referencia.
4. Una respuesta con formato inválido no se muestra como respuesta válida.
5. Los errores preservan la pregunta, permiten reintento manual y no duplican el mensaje del usuario.
6. Las preguntas sucesivas de la misma página reutilizan el UUID de la respuesta anterior; al desmontar y volver a montar la página, la primera petición no envía el ID previo.
7. La página funciona con el sistema visual, el tema y los tres idiomas existentes.
